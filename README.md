# Sổ Tay Sinh Viên - Landing Page

Trang giới thiệu ấn phẩm cẩm nang học đường dành cho tân sinh viên và học sinh chuẩn bị bước vào giảng đường đại học.

## Giới thiệu
Landing page được thiết kế theo phong cách xuất bản hiện đại, giao diện trực quan, tương thích hoàn toàn trên thiết bị di động và máy tính:
- **Hero Section & Mô phỏng sách 3D (Pure CSS):** Tạo ấn tượng thị giác sống động cho ấn phẩm.
- **Lợi ích cốt lõi:** Trình bày 4 giá trị định hướng thực tế.
- **Cấu trúc 4 phần nội dung & Trích đoạn tương tác (Interactive Excerpts):** Tab xem nhanh các mẹo học tập, quản lý chi tiêu và làm việc nhóm.
- **Đối tượng độc giả mục tiêu:** Phân loại rõ ràng cho học sinh THPT và tân sinh viên năm nhất.
- **Biểu mẫu đăng ký nhận thông tin:** Kết nối tự động với Google Sheets qua Google Apps Script Web App.
- **Trích đoạn xem thử dạng Modal tương tác.**

## Công nghệ sử dụng
- **HTML5 & Semantic Elements**
- **CSS3:** Custom Properties (Design Tokens), Flexbox, CSS Grid, 3D Transforms, Responsive Design
- **Vanilla JavaScript:** Mobile menu, Scrollspy navigation, Modals, Tab switcher, Form submission handler

## Cấu trúc thư mục
```
├── index.html       # Mã nguồn chính của trang landing page
├── styles.css       # Toàn bộ hệ thống giao diện, hiệu ứng và typography
└── README.md        # Tài liệu hướng dẫn dự án
```
